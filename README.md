# AndyPortfolio

Rails 7 portfolio application whose root route renders the blog index (`root "blogs#index"` in `config/routes.rb`).

## Stack

- Rails 7 (`~> 7.0.4`)
- Ruby 3.2.0
- PostgreSQL
- Puma
- importmap-rails
- Minitest

## Setup

```sh
bin/setup
```

Prerequisites: a working Ruby 3.2.0 toolchain (matching `.ruby-version`), Bundler, and a reachable PostgreSQL instance configured per `config/database.yml`.

## Run

```sh
bin/rails server
```

## Tests

```sh
bin/rails test
bin/rails test test/integration/
```

Tests use Rails Minitest under `test/`, with integration coverage in `test/integration/`.

## Production build / deploy

```sh
bin/render-build.sh
```

`bin/render-build.sh` runs `bundle install`, `bundle exec rails assets:precompile`, and `bundle exec rails assets:clean`. The Render blueprint in `render.yaml` wires this script as `buildCommand`, with `preDeployCommand: bundle exec rails db:migrate` and `startCommand: bundle exec puma -C config/puma.rb`. See [`docs/deployment-render.md`](docs/deployment-render.md) for the full Render handoff.

## Required env vars for production

Declared in `render.yaml`:

- `DATABASE_URL` (provided by the `andyportfolio-db` Render Postgres database)
- `RAILS_ENV` (`production`)
- `RAILS_LOG_TO_STDOUT` (`1`)
- `RAILS_SERVE_STATIC_FILES` (`1`)
- `RAILS_MASTER_KEY` (set manually from the Rails credentials master key)
- `BLOG_ADMIN_TOKEN` (set manually to a secret string Andy controls)
- `SECRET_KEY_BASE` (generated by Render)
