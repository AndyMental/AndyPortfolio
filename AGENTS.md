## Setup

```sh
bin/setup
```

`bin/setup` runs (in order, observable in `bin/setup`):

1. `gem install bundler --conservative`
2. `bundle check` → `bundle install` on miss
3. `bin/rails db:prepare`
4. `bin/rails log:clear tmp:clear`
5. `bin/rails restart`

Prerequisite: a working Ruby 3.2.0 toolchain and a reachable PostgreSQL instance configured per `config/database.yml`.

## Tests

```sh

bin/rails test test/integration/
```

Checked-in tests use Rails Minitest under `test/` with `test/test_helper.rb`; `rails/test_unit/railtie` is required in `config/application.rb`. `test/test_helper.rb` parallelizes by processor count. No `spec/` directory and no RSpec gems are declared.

Integration suites (`test/integration/`):

- `blog_body_rendering_test.rb` — verifies `blogs#show` strips unsafe markup (`<script>`, inline `on*` handlers, `javascript:` URLs, `<img>`) while preserving safe formatting tags.
- `blog_admin_gate_test.rb` — verifies the `BLOG_ADMIN_TOKEN` gate on `blogs` write/destroy actions (anonymous reads succeed, anonymous writes return 404, the `X-Blog-Admin-Token` header unlocks writes only when it matches the env value).
- `blogs_index_test.rb` — verifies `root` and `blogs#index` render the public blog list.
